Conectar o ProvaScan ao Google Drive

A integração está preparada. Para o Google permitir a conexão, o proprietário precisa registrar o aplicativo e obter seu ID público de cliente Web. Essa configuração não exige compartilhar a senha da conta.

  1. Entre no Google Cloud Console com a conta que administrará o aplicativo. Crie ou selecione um projeto para o ProvaScan.
  2. Na biblioteca de APIs, ative a Google Drive API.
  3. Configure o Google Auth Platform / tela de consentimento com o nome ProvaScan e seu contato. Para teste pessoal com Gmail, configure audiência externa em teste e inclua seu próprio e-mail como usuário de teste.
  4. Declare a permissão https://www.googleapis.com/auth/drive.file, para os arquivos criados ou autorizados para o aplicativo.
  5. Crie um cliente OAuth do tipo Aplicativo da Web. Nas origens JavaScript autorizadas, informe https://marciomarx.github.io, sem o caminho /provascan/.
  6. Copie somente o ID do cliente, terminado em .apps.googleusercontent.com. Não copie o segredo do cliente, senha ou token.
  7. Volte ao ProvaScan e cole esse ID em Configuração inicial da conexão. Para disponibilizá-lo a todos os seus aparelhos, o mesmo ID deve ser publicado no arquivo de configuração do aplicativo.

Depois de configurar

Exporte um backup no notebook e outro no celular. Conecte primeiro o notebook e espere a confirmação de sincronização. Depois conecte o celular com a mesma conta e o mesmo ID de cliente. O aplicativo reúne os cadastros e destaca versões diferentes do mesmo registro para conferência.

A janela do Google abre ao tocar no botão Conectar. Durante o teste, o Google pode apresentar avisos próprios da configuração do aplicativo. A publicação para outros usuários depende dos requisitos apresentados para o projeto.

Se o Google solicitar a política de privacidade, use https://marciomarx.github.io/provascan/privacy.html.
